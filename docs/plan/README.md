## 维护规则

- 每周计划、组长审核、验收表和实验记录分别存入对应的 `weekN/`；实验记录可使用 `weekN/records/` 子目录，模板见 [实验记录模板](../templates/experiment_record.md)。
- 新增周次时同步更新本索引；移动或重命名文档时同步修正文档导航及相对链接，不在旧目录保留并行维护的副本。
- 计划记录目标、分工与验收标准；验收表记录实际完成情况、证据、限制和待办。未运行、未收到或待补证应如实区分。
- 更新验收状态时标注更新日期；保留历史实验日期、版本、来源和适用边界，不用新环境信息倒填旧实验。
- 原始日志、CSV、二进制等生成物继续保存在 `results/` 或团队归档存储，不提交 Git；文档记录路径、运行编号、哈希和获取方式。本地归档链接不代表分发后其他成员可以访问。
- `docs/DEVELOPMENT_PLAN.md` 保留为项目总体路线图，架构和技术说明仍放在各自目录，不代替按周执行计划。
