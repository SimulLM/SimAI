One warmup and one measured 512-input/64-output request on the configured dual-H800 FP16 TP1 1P1D service after the router first-count guard change. Both return HTTP 200 and expected token counts, with first router completion count 1, first client chunk count 1, and `finish_reason=length`. Router IDs, producer and consumer backend IDs and ordered CLOCK_MONOTONIC events are preserved in the raw archive; `audit.py` verifies the router/consumer ID match and first-token ordering. The measured server arrival-to-stream-complete was 0.845082785 s, router first-token to client observation 0.048023 ms, and final choice to router completion 0.199536 ms. These are observations from one measured request, not production distributions or an additive cost model.
