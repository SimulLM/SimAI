# Independent serial calibration and prior provenance

An audit of the previous merged 192 calibration rows found that each 32-request serial repeat was assembled from 16 requests in the main collection and 16 in a later supplement, so the previous merged serial repeats do not satisfy the planned uninterrupted independent-repeat structure. All 192 input hashes were reconstructable, source rows matched, and adjacent client waves within each collection did not overlap; this does not prove GPU idle or KV cleanup. The supplement had written its 48 requests before failing an incorrect 144-row assertion; those historical rows are preserved as diagnostics.

To repair only that gap, three independent service restarts each ran four warmups and then 32 sequential 512-input/64-output streaming real 1P1D requests. All 108 including warmups completed with expected lengths, distinct saved token arrays, matching router/backend IDs and host boundary order; each service was stopped and both GPU memories reported zero after each repeat. The measured per-repeat median server E2E times are 1033.762, 899.177 and 862.398 ms. First and last eight medians in repeat 0 were 854.89 and 1298.31 ms respectively, with max 1718.31 ms; cause is not established. Repeat 1 medians were 900.39 and 878.41 ms; repeat 2 were 861.74 and 863.17 ms, max 1668.65 ms. Do not claim stable calibration or discard outliers. GPU clock/power during each request was not captured; service restart and sequential client completion do not by themselves prove KV cleanup after warmup.

Raw request token arrays, router/server logs, start scripts, exit codes, audit and resource snapshots are in raw.tar.gz. These are calibration observations, not fitted fees or formal validation. Concurrent calibration, non-overlapping CPU/GPU/KV fee accounting and scheduling compatibility remain outstanding; no freeze and formal validation 0/30.
