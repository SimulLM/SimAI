# Batch-3 component extraction and separate attention candidates

This reuses raw events from the earlier batch-3 run and the 1024-token supplement. For each of eight context bins and separately for uniform and mixed contexts, the audit summarizes layer-16 component CUDA events by distinct wave; the full-forward entries exactly match all 16 cells in the previous independent full-forward audit. Each of the 160 component cells has at least 10 warmup and 30 measured waves. Timing instrumentation and synchronization perturb execution, and per-component medians must not be summed to infer whole-step time.

The existing candidate v5 attention profile had no decode batch-3 entries. The builder produces two alternative tables, adding eight layer-16 `attention_combined` entries for each context type; all 47 original rows are unchanged and no value is derived from calibration or validation completion. The input profile, both candidates, audit, manifests, and scripts are included. The adapted predictor lookup uses batch size and rounded mean context and does not select by mixed/uniform status, so neither candidate is a complete mixed-workload model. If used for an explicitly labelled diagnostic, both comparators must use the same candidate. These are not frozen fees, and no improvement or hardware accuracy claim is made.

The mixed/uniform attention medians differ from -0.41% to +3.53% across the eight bins, but the measurements are not randomized paired trials and run composition differs; these numbers do not isolate the effect of mixed context or justify pooling. `attention_combined` includes the instrumented attention/KV operation, not a full model step. CPU, KV transport, logits, sampler, router, scheduler and overlap remain outside this extraction. Actual service batch scheduling and the simulator's KV pull ordering remain unresolved. Formal validation remains 0/30.

Reproduce using `audit-components.py` with the two original run directories and a fresh output directory, then `build-attention-candidates.py` with the included base table and generated components CSV.
