# Isolated first calibration request: interim boundary check

This replays only the first measured request of the existing serial 512/64 calibration run, from its actual server arrival as simulation time zero. Its input IDs, hash and real router events are preserved here. The previous 32-request actual-arrival replay is not an isolated serial simulation: request 1 arrives at about 0.870 s, before the slower simulated request 0 completes. The isolated replay removes that later-request interference without changing candidate fee inputs.

Real CLOCK_MONOTONIC router arrival 1818510180734341 ns; Prefill HTTP send 1818510180839530 ns; producer response received 1818510209246258 ns; Decode HTTP send 1818510209332395 ns; first streamed token observed by router 1818510224313730 ns; response stream completed 1818511048434602 ns. The router completion is after consuming and yielding the response stream, not a timestamp of last GPU kernel completion. Real server interval is 0.867700261 s. GPU Prefill, transfer completion, GPU KVReady and Decode queue boundaries were not recorded for this same calibration request; they cannot be reconstructed from router timestamps.

Candidate DAG and adapted baseline isolated E2E are respectively 1.0525376307540713 s and 1.0525376307541063 s; both report 512 input and 64 output tokens. DAG reports Prefill complete 0.023397013351301198 s, transfer started at the same time and GPU KVReady/first Decode start 0.03125546923365414 s, simulated completion 1.0525376307540713 s. These are simulator events, not observed hardware timestamps. DAG reports 268435456 wire bytes while adapted baseline reports 268959744 bytes; both report 0.007858455882352941 s transmission time. Their byte accounting needs investigation before declaring cost semantics aligned. The latter is a predictor-adapted baseline, not the untouched original; candidate costs/configuration are not frozen.

Separate instrumented 512/8 evidence in `pd-first-token-dual-sampling-20261126` shows producer and consumer both perform logits/sampling, the router sends the producer response to itself and streams the consumer response, and the consumer executes one KV-bypass prompt step followed by seven decode steps. That is not a trace of this 512/64 request and does not prove token equality across endpoints. The simulated lifecycle counts a token during Prefill, creating an unresolved consumer first-token cost/semantic mismatch. No timing compensation was fit. No validation was performed.
