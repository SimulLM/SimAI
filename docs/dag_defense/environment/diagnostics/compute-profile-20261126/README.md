# Independent vLLM compute diagnostics

This profile ran on GPU0 of the new H800 PCIe server using vLLM 0.8.5, PyTorch 2.6.0+cu124, transformers 4.51.3, FP16, TP1 and the fixed local NousResearch model. The vLLM log reports Flash Attention. Hooks recorded CUDA event intervals around nine modules in transformer layer 16, including QKV projection, RoPE, combined attention/KV handling, output projection, two fused residual/RMSNorm operations and MLP operations. The actual model config reported `rope_theta=10000.0`, `rope_scaling=null`.

The diagnostic server used eager mode, prefix caching and chunked prefill disabled, 4096 maximum batched tokens, maximum four sequences and a 0.65 GPU memory fraction. Each model step synchronized after its CUDA events. These hooks and synchronizations perturb scheduling and timings; these samples are not service E2E latency. They measure only one middle layer, not embeddings, final norm, output head, scheduling, or all 32 layers. GPU event intervals can include stream idle caused by host dispatch. No result is a formal validation request.

The client made 2,900 independent synthetic token-input requests across five recorded client runs, each with two forced output tokens and EOS ignored; all succeeded and each maps to exactly one prefill and one decode model step. Two additional unmatched steps belong to the initial six-token hook smoke. Samples retain warmup labels, actual batch composition and IDs. Target coverage includes prefill lengths 512 and 1024 with batches 1/2/4, 2048 with batches 1/2, and decode contexts 513/576/639, 1025/1088/1151 and 2049/2112/2175 with batches 1/2/4. The 2048-token prefill wave of four is split under the 4096-token scheduler cap. All 35 target shapes have at least 30 eligible samples after ten same-shape warmups; `target-coverage.json` lists counts. The six additional prompt lengths were used to sample longer decode contexts, and are independent of the validation input set.

These measurements cannot yet be imported unchanged into either simulator. The predictor currently ignores its separate RoPE field; layernorm and residual are fused in this vLLM implementation; and the measured attention interval combines operations the predictor models separately. Define and validate a common mapping and interpolation, include CPU overhead and remaining model work, and use the same derived cost files for both simulators before freezing. Profile costs must not be tuned using validation completion times. The 128-token decode trajectories and mixed-batch behavior still need independent compatibility checks. The server was intentionally stopped after sampling (exit 143). Original server and event logs plus client records are preserved compressed; decompressed copies are retained on the server.
