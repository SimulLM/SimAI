# Single-request GPU forward and simulated layer costs

The same 512/64 calibration input was repeated in the separately synchronized instrumented service. Its 63 consumer Decode GPU forward events were joined in order, with sequence lengths 513 through 575, to the isolated candidate DAG's 63 Decode iterations. The simulator lifecycle's single-request numerical context mapping was separately checked in `pd-decode-context-semantics-20261126`. The real and simulator data are from different runs; timestamps must not be combined across them.

For this one request, measured full-model forward median is 13.87165 ms and candidate 32-layer attention/MLP sum median is 15.19147 ms; paired difference median is 1.31982 ms (range -2.83218 to 1.59572 ms). Each iteration's context, timing and source timestamps are retained. The real whole-model event includes embeddings/final normalization and may contain stream idle; it excludes the connector, logits and sampler. The simulated sum consists of separately predicted layer components and is not identical in scope. Instrumentation and synchronization perturb the real service, and the 63 steps are correlated within one request, not independent samples. This finding identifies an accounting/model mismatch to investigate; it is not a fitted correction or proof of inference accuracy. No validation data were used.
