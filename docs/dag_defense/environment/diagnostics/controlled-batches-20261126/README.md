# Controlled batch membership checks

CPU-only synthetic trace diagnostics, not measured PD performance or validation. Each trace uses 512 input/64 output; arrival seconds are 0 and 0.010 (staggered two), 0 and 0 (simultaneous two), and four zeros (simultaneous four). All nine runs exited 0. They reuse the same original predictor and 255 Gibit/s modeled transfer across untouched original, separately corrected admission baseline, and DAG. The corrected baseline differs from the original only in modeled decode-ready queue admission and wake; DAG retains its own scheduling/resource dependencies. See the earlier early-batch-minimal checkpoint for the patch and wake tests. Model config network-device name is a simulator label, not an assertion of NVLink; physical topology is SYS.

Matching includes both phases, replica, request IDs, per-request token counts and prior decode count. In staggered two, original vs DAG matched 4/66 original and 4/67 DAG; corrected vs DAG matched 67/67 on each side. Original's second decode batch includes request 1 6.340 ms before its modeled ready time; the corrected second batch and DAG both contain only request 0. Corrected/DAG then have matching memberships throughout this case; their third decode starts at 64.961 and 72.820 ms respectively. In simultaneous two and four, all three report 64/64 matched batches with no early membership; first decode starts baseline/DAG at 50.714/58.572 ms and 88.573/112.148 ms respectively. Matching batch task costs agree within 1 ns in these three cases, excluding resource wait. This makes no claim for unmatched shapes, other traces, production costs or real completion timing. It does not resolve wait ownership or eliminate the separate modeled start-time differences. Both simultaneous cases lack the triggering early admission in original.

Raw traces, logs, commands, metrics, and exit codes are in the hashed archive on the data disk; recreatable pickle caches excluded and remain in the original run directories. No validation data was used. Freeze remains open on real fee scopes/coverage, idle/cleanup and arrival/completion mapping, independent of any near-zero error criterion.
