# Existing 1024/2048 Decode logits profile coverage

Reanalysis of the real FP16 TP1 dual-H800 `pd-kv-ready-bound-20261126/raw.tar.gz`, not a new GPU run or formal validation. The script joins 560 successful 1024/2048-input, eight-output requests to Decode IDs, checks exactly seven subsequent Decode events per request, and deduplicates shared actual batch steps by `(pid, host_start_ns)`. `wave-medians.csv` retains each wave, requested concurrency, actual batch size, warmup flag and per-wave median of distinct logits CUDA-event intervals. There are 1,814 distinct Decode steps. GPU event timings, device sync and hooks perturb the service and event durations may include stream idle gaps.

Aggregating by input length and actual batch across separate requested-concurrency waves, seven of eight 1024/2048 x actual batch 1/2/3/4 groups contain at least 10 warmup and 30 measured waves. The remaining 2048/batch-4 group contains 10 warmup and 29 measured waves, below the plan's threshold. Group median wave medians range 0.1461–0.1472 ms. They share one service session; waves are not independent server restarts. Grouping is descriptive, not evidence that requesting concurrency N yields actual batch N.

Each request has eight outputs and only seven subsequent Decode steps. These measurements cover neither full 128-output context evolution nor mixed input lengths, and do not establish physical additivity with sampler host calls, producer logits, or an accepted cost for the validation matrix. No implicit interpolation or zero-filling is permitted. Use `analyze.py` after extracting `compute-events-86396.jsonl`, `compute-events-86401.jsonl`, `router-events.jsonl` and `coverage/requests.jsonl` from the hashed archive into its working directory. Raw and derived artifacts are at `/root/autodl-tmp/dag-handoff/runs/logits-coverage-20261126/`. Formal validation remains 0/30; no fee was frozen.
