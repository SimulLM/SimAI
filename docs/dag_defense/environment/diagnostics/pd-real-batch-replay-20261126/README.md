# Real instrumented wave replay: Decode batching

Reuses a previously captured real dual-H800 1P1D eager 8-output-token diagnostic with CUDA synchronization and instrumentation. For each of 1024/2048 input lengths and requested concurrency 1/2/4, wave 10 was selected before inspecting its replay, and the original per-request router arrival timestamps were replayed in both DAG pull candidate and adapted baseline. All 12 simulator runs exited 0; request metrics explicitly verify input and output token counts. The common candidate cost profile and communication bandwidth are used by both; no validation request was run.

The audit joins backend IDs to actual consumer model-step events. For each request's Decode step index it compares that step's complete batch membership with the simulator. Both serial cases match 7/7 request-steps for each simulator. For 1024 concurrency 2, DAG matches 8/14 and adapted baseline 10/14; concurrency 4 both match 4/28. For 2048 concurrency 2 they match 6/14 and 10/14 respectively; concurrency 4 both match 3/28. For example the measured 2048/concurrency-4 wave has six Decode steps with batch size 4, while both replay variants form smaller batches in that wave. These fractions characterize one selected wave, not a required target or overall experiment percentage.

This evidence shows a service/simulator grouping discrepancy on these captured requests, not an error attribution or proof that either simulator should exactly copy every real batch. Hooks and synchronization perturb real scheduling; only one wave per shape and eight output tokens were inspected, and the router provides a buffered diagnostic rather than formal E2E. The time-varying scheduler, overhead, and transfer-resource hypotheses remain to be validated before freezing. The baseline is adapted, not the pristine checkout. `summary.json` retains all distributions. Full request maps, traces, profiles, commands and outputs are in the data-disk archive named by `raw-archive-sha256.txt`; raw real events are in sibling `pd-flow-boundary-20261126/raw.tar.gz`. Formal validation remains 0/30.
