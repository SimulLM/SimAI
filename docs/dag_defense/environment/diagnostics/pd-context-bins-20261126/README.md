# Decode forward context-bin candidate

Independent detailed profiling, not formal E2E or a frozen cost. In vLLM 0.8.5 eager 1P1D FP16, the original run used 1024/2048 input, 128 output, requested concurrency 1/2/4 and 10 warmup + 30 measured waves per shape. The supplement used the same mode and lengths, requested concurrency 2/4 and 20 warmup + 40 measured waves per shape; all 720 supplementary requests returned HTTP 200 with expected input/output lengths and exit 0. Both GPUs released. Raw supplementary events and request/router logs are in `/root/autodl-tmp/dag-handoff/runs/pd-context-supplement-evidence-20261126.tar.gz`, with digest in this directory. Original raw data are in the earlier pd-full-context-20261126 evidence.

Each Decode model-forward event is joined via backend ID to a single client wave and grouped by actual batch, input length, mixed/uniform status, and integer mean sequence length rounded up to a 16-token block. The rounding mirrors a feature in the simulator, but exact equivalence between vLLM seq_lens and simulator processed-token semantics remains to be checked. Reject mixed waves, mixed phases, missing shapes and context spans greater than one. Take a median per independent wave then across waves; each selected source must independently have at least 10 warmup and 30 measured waves. The merge selects a source for each eligible point and never pools raw repetitions between runs.

Fifty eligible points result. For each input, actual batch 1 has eight uniform bins; 1024/batch2 has eight uniform bins, 2048/batch2 has eight mixed bins; both batch4 cases have eight mixed bins. Batch3 has one uniform end bin for each input, so intermediate batch3 coverage remains missing. Uniform and mixed samples are kept distinct; same rounded average is not proof of equal actual attention cost. These are full-model-forward CUDA-event intervals, which may include GPU gaps and omit logits, sampler, CPU, router and KV. Synchronized instrumentation changes scheduling; no missing points were filled. Complete non-overlapping accounting and calibration are pending. Formal validation remains 0/30.
