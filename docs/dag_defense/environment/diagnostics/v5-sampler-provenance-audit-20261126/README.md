# Candidate v5 sampler source and boundary audit

All 17 `sampler_e2e_median` values in the historical v5 CPU profile exactly match the corresponding phase, input length and batch medians in the independently measured synchronized sampler summary; each source row has at least ten warmups and 30 samples. The historical profile manifest lists the source path but omits its SHA-256. This audit preserves the source summary and independently records its digest without rewriting the historical manifest or changing candidate costs.

The historical mapping-contract label `synchronized_sampler_cpu_only` is misleading: its measured host interval starts after a device synchronization, runs `Sampler.forward`, and ends after another device synchronization. It contains sampler CPU operations, GPU sampler work and waiting, and is not an isolated CPU-only fee. The separately profiled middle-layer GPU forward excludes logits and sampler, but that alone does not establish all CPU/GPU scheduling overlaps, output-head accounting or consumer first-token behavior. This audit establishes provenance and values, not physical cost validity or formal acceptance. No validation results were used.
