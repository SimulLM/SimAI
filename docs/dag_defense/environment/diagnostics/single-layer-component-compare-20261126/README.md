# Single-request layer-16 component comparison

For the same 512/64 input and isolated candidate replay, 63 real Decode layer-16 CUDA events from the separately instrumented repeat are aligned by request ID, step order and contexts 513–575 with candidate layer-16 attention and MLP component fields. Pre-projection and RoPE follow the candidate mapping and are grouped together; combined attention includes the candidate cache-save bucket. Every underlying component and step is in components.csv.

The observed combined-attention median is about 0.16925 ms while the candidate median is about 0.13131 ms, even though the whole-model forward comparison showed the candidate layer sum larger than the measured full-forward event. Other component differences are listed in summary.json. These different directions warn against assigning the full-model discrepancy to one component or multiplying a single layer's difference by 32. The 63 observations are correlated steps from one request; component CUDA-event intervals can overlap or contain stream gaps, and the candidate and measurement were obtained in different sessions. Component medians cannot safely be summed to infer a full-step or E2E correction. No fee was changed, no formal validation data were used, and this is not a final accuracy claim.
