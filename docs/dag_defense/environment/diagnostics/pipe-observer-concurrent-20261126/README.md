# Concurrent warmup and connector host-state diagnostic

Four distinct 512-input/8-output requests were submitted concurrently to real two-H800 1P1D and all succeeded. Four observations, five seconds apart after completion, showed zero router in-flight requests, zero visible vLLM running/waiting/swapped/cache gauges, zero SimpleBuffer queue entries/bytes and zero active observed insert/select/data-pipe calls. Producer insert and consumer select started/completed counts were each 4; producer data-pipe send/receive counts were 20/8 and consumer 8/20, with all started calls completed and zero buffered send bytes. Snapshots were less than 1.5 s old. Both GPUs were released after shutdown.

The observer adds a background thread and Python wrappers; its timing impact is not characterized. Data-pipe host return or zero buffered bytes do not establish asynchronous GPU completion. Signal-pipe work and all possible CUDA/network operations are not fully observed; samples may miss transients. Only successful requests were tested; timeout, crash and interrupted transfer cleanup remain unverified. The existing idle probe correctly returns 2 (connector/GPU readiness unverified). This is stronger diagnostic evidence, not a formal idle certification or validation. Raw events, gauge samples, warmup results, logs and exit codes are preserved in raw.tar.gz.
