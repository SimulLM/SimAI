One warmup split into actual batch 1+3, so batch 4 has 11 warmup and 30 measured distinct waves. Its post-KV-sync to first-step sync return median is 0.665459 ms (min 0.648841, p95 0.755127, max 0.791520). The prior session with 9/30 valid batch-4 warmup/measured waves is preserved separately, not pooled or relabelled as qualified. Request-to-step IDs, all wave values, source hashes, service/launcher/condition and logs are preserved.

The proxy deliberately waits for all four Prefill responses before Decode submission to obtain this shape. Instrumentation synchronizes tensors and changes scheduling; this is an eight-output, non-streaming diagnostic in one service session, not uninstrumented 128-output E2E.
