# Matched batch costs in independent calibration replay

This audit reuses the six completed 512/64 independent calibration arrival replays and compares the DAG task-duration sum with the adapted baseline's batch execution duration. Batch keys include replica, request IDs, each request's prior Decode step count and token counts. DAG resource waiting is excluded from task cost. The audit does not compare costs for unmatched batches, validate individual operators, or prove real service/simulator equivalence.

Across the six cases, 5794 of 8566 DAG batches matched a baseline batch (67.6%; 5794 of 8584 baseline batches). All 5794 matched batch costs agree within 1 ns; there were no duplicate keys or graph mapping errors. For serial runs 5305/5545 DAG batches matched (95.7%); for requested concurrency 2, 489/3021 matched (16.2%). All 192 Prefill batches matched; most concurrent differences arise in Decode batch histories. Different batch histories are expected to prevent direct per-batch pairing, and do not themselves prove unequal cost functions or explain service accuracy. Exact per-case counts and per-batch differences are in summary.json and matched.csv.gz.

The common candidate profile and explicit bandwidth were verified in the preceding replay checkpoint. The original baseline here is an adapted predictor, not the untouched baseline. Original trace, source and logs are in `pd-pull-calibration-replay-evidence-20261126.tar.gz` referenced by the preceding checkpoint; the audit script is `scripts/dag_defense/audit_calibration_batch_costs.py`. This is calibration diagnostics, not formal validation; costs and compatibility are not frozen.
