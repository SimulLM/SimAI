# Optional attention context-shape lookup

The DAG checkout and independent adapted-baseline checkout contain identical predictor changes (source SHA-256 `423ce8cd2af42f5123f24a278918ca70f51f1fdaec7fab8b565ec9986e328d3e`); `adapted-baseline.patch` is the complete diff against pinned baseline cef83f9ddd96540e3e9f48934f11335d52d54fce, including earlier profile adaptations. The untouched baseline checkout retains no tracked modifications. Do not label the adapted comparator untouched original.

The optional `context_shape` profile column permits exact classified cells to distinguish uniform context (span 0) from mixed context (span 1). For a classified key an unsupported span or missing class raises an error; classified data is excluded from the shape-blind regression training. Legacy rows and uncovered keys retain prior fallback behavior; this is not a strict complete-coverage gate. The supplied candidate preserves the 47 earlier unclassified rows and adds 8 uniform plus 8 mixed cells from independent CUDA profiling. No fees have been frozen.

Tests ran independently against both checkouts: legacy behavior, class selection, rejection cases, fallback and training exclusion passed; all 16 actual candidate cells selected expected values. Existing lookup and profile mapping tests passed 7/7. A three-request synthetic-arrival simulator smoke with the same candidate profile exited 0 in both adapted baseline and DAG; its logs, source commands and artifacts are archived at the absolute path in `raw-archive-sha256.txt`. This is a functional test, not real inference calibration, validation, or proof of scheduling parity.

The measured classified bins cover only actual batch 3 at 1024-input contexts. Matching the simulator request counters to real mixed-batch shapes remains to be demonstrated; the two simulators can form different batches. Remaining CPU/router, KV scheduling and non-overlapping costs, resource occupancy, and independent calibration remain unresolved. Formal validation remains 0/30.
