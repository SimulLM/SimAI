# Streaming 1P1D router diagnostics

Two local, real 1P1D diagnostic runs used GPU0 for Prefill, GPU1 for Decode, FP16, TP1, eager execution, a maximum batch of four and 4096 batched tokens, prefix and chunked prefill disabled, and an 8 GiB KV buffer limit. The router records server API arrival, backend dispatch and response, backend IDs, first token, completion or error with CLOCK_MONOTONIC. Client events use the same host clock. Server completion is recorded after the backend SSE stream finishes and its lines have been yielded by the ASGI generator; it is not the client receive time. The proxy writes small JSONL records in the request path, so its overhead is part of the server boundary and must be considered in compatibility/calibration.

The v1 run completed a real 512-input/8-output request and confirmed that a deliberately invalid model fails Prefill with 404 and does not reach Decode. Its first-token event was based on the first nonempty text delta, which may be later than the first generated token; it is retained as historical diagnostic evidence only. The v2 router enables vLLM continuous usage statistics and marks first token on the first SSE message with a positive completion-token count. The v2 single-request verifier passed: the server and client ID mapping, monotonic ordering, 512 input tokens, eight output tokens, DONE and token counts 1 through 8 were checked; a deliberately invalid model again failed before Decode.

A separate v2 wave of four unique 512-token prompts also returned four successful eight-token streams with distinct Prefill and Decode IDs, positive first-token observations, final usage and completion events. The concurrent verifier passed. API-level ID mapping is established, but KV tensor-to-request association inside concurrent backend batches is still not independently instrumented. These are smoke inputs, not calibration or validation, and the observed times are not benchmark results. Router/client scripts, raw SSE, logs and both successful and intentional-failure records are included. Servers were intentionally stopped after tests (exit 143).
