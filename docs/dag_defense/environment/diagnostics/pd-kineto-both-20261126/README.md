# Both-rank GPU profiler diagnostic

Independent PyTorch Kineto/CUPTI profiler on real vLLM 0.8.5 eager 1P1D FP16 TP1, input 1024/output 8, requested concurrency 4. The diagnostic router buffered responses, and profiling and exports perturb service. All 104 client requests succeeded; profilers each captured 28 prefill calls following two warmup calls and did not cover every client request. Producer engine PID 99091 and consumer engine PID 99096 are identified in server logs; each sees its own physical GPU as CUDA device 0. Both profilers finished and both GPUs were released.

Producer trace contains 371 NCCL and 15241 other GPU kernel events, all context 1 stream 7; one NCCL/other pair shows a 0.255 microsecond same-stream boundary overlap. Consumer contains 392 NCCL and 46532 other GPU kernel events, all context 1 stream 7; no interval overlap. Same-stream submicrosecond timestamp intersection is not evidence of GPU kernel concurrency. Findings support same-stream kernel serialization within captured windows, not exclusive occupation of both GPUs over the whole connector transfer, exact request-level payload mapping, or uninstrumented behavior. This scope does not establish full validation workload semantics or solve CPU, first-token and transfer accounting. Formal validation remains 0/30.

Raw trace archive with server/client/router logs and process mappings is at `/root/autodl-tmp/dag-handoff/runs/pd-kineto-both-evidence-20261126.tar.gz`, hash in raw-archive-sha256.txt.
