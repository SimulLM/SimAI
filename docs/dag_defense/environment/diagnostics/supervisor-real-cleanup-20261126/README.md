# Real supervisor cleanup after pre-response cancellation

A dual-H800 1P1D service was started by the process-group supervisor for this diagnostic. A controlled local client cancelled after server arrival but before response headers. The server subsequently completed Prefill, sent Decode and logged `CancelledError`; the diagnostic collector wrapper then returned exit 1. The supervisor recorded `collector_failed`, restart-required, terminated its service process group and verified the group gone; `nvidia-smi` reported 0 MiB on both GPUs afterwards. Raw service and router logs, client timestamps, commands and supervisor status are retained. This is one real failure case; the injected permissive gate and failure wrapper are diagnostic-only and cannot authorize formal collection. A process that escapes into a different session is outside the process-group guarantee. Fresh service readiness and failure recovery remain separate checks. Formal validation is 0/30.
