# Candidate Decode-pull replay of independent calibration

Six existing independent real 1P1D calibration repetitions were replayed using router CLOCK_MONOTONIC arrival times: serial and requested concurrency 2, three repetitions each, 32 requests per repetition, 512 input and 64 output tokens. Request token hashes, expected lengths, backend mappings and monotonic server boundaries were checked before replay. All 12 simulator runs (DAG and adapted baseline per repetition) exited 0, and 192 measured requests were joined by the trace-generated request IDs to observed router completion and both predictions. This is diagnostic calibration, not validation. Existing real observations are retained and were not used to fit the candidate costs.

Both simulators use the same candidate profile files and explicit 255 Gibit/s communication parameter. Each pair generated 24 prediction CSVs with identical hashes. This verifies configured inputs and prediction tables only; differing execution batches, direct lookups, timing boundaries and resource contention still prevent a blanket identical-evaluated-cost claim. The baseline is adapted from pinned `cef83f9ddd96540e3e9f48934f11335d52d54fce`, not the untouched original.

The six observed per-repeat median E2E values range from 0.862 to 1.299 seconds; DAG candidate median values range from 1.063 to 1.141 seconds and adapted-baseline values from 1.055 to 1.106 seconds. Per-repeat DAG mean absolute error ranges from 0.169 to 0.348 seconds; baseline ranges from 0.167 to 0.321 seconds. See `requests.csv` and `summary.json` for all rows and per-case values. These are descriptive diagnostics, not a ranking or accuracy claim: router and simulator time boundaries are not yet proven equal, fees and occupancy are provisional, and the real measurements show substantial variability. Separate service starts do not prove KV cleanup immediately after warmup.

Raw simulator event output, commands, trace inputs, request maps, prediction CSVs, source snapshots and profile files are archived at the path in `raw-archive-sha256.txt`; reconstructible pickle caches and lock files are excluded. Real calibration source files and hashes are recorded in `manifest.json`. `replay_independent_calibration.py`, `audit_independent_calibration_replay.py` and `audit_calibration_common_cost.py` reproduce the replay and audits into new output paths after adjusting their fixed output directory to avoid overwrites. Formal validation remains 0/30; no parameter freeze is established.
