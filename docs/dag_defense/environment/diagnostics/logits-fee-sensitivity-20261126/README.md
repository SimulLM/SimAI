# Decode logits scope: serial sensitivity only

The independent full-model forward event excludes logits and sampler, and the v5 synchronized sampler interval begins after a synchronization immediately before `Sampler.forward`. Existing producer layer work and scheduler/prepare/output-processing profiles do not establish that Decode logits are covered; it is an identified candidate scope gap, not proof that unsynchronized wall time lacks exactly this amount. Reanalysis of the independent `pd-accounting-20261126` instrumentation selected 30 warmed serial 512/64 requests, each with 63 consumer Decode steps and batch size one. The median of per-request medians for CUDA logits events is 0.146624 ms (range 0.146368–0.259296 ms; p95 0.252608 ms). These are correlated per-step samples within one service session, events can include idle gaps, and instrumentation perturbs behavior. Source hashes and each request's median are saved. They were not selected using validation or E2E error.

An isolated, opt-in sensitivity builds on `whole-forward-replay-20261126`: an additional 0.14662399888038635 ms logits cost is placed once after each of 63 Decode forward tasks and before the finish task. It is not added to the distinct consumer-first-token interval, which already contains logits and sampling. The predictor-adapted baseline includes the same addition in each corresponding Decode model duration. Both processes exit 0. Graph audit finds exactly 63 forward-plus-logits Decode graphs with no per-layer tasks, and one unchanged Prefill graph. Both predicted E2E values increase by exactly 9.237312 ms, from 0.939207 s to 0.948444 s. This is an accounting sensitivity, not an accuracy improvement, pristine-baseline result, physical non-overlap proof or frozen fee.

In particular, host sampler calls can wait for GPU work; adding unsynchronized host sampler measurements and GPU durations would double-count. Even with synchronized profiling, separate runs and synchronization introduce uncertainty and may not preserve the production overlap. Prefill logits, route/output tail, 1024/2048, batch sizes and mixed contexts are not closed. Do not use this single-shape number as a universal fee. Full source events are in `pd-accounting-20261126/raw.tar.gz`; all scripts, graph outputs, command logs and exit codes are in `/root/autodl-tmp/dag-handoff/runs/logits-fee-sensitivity-20261126/`. Formal validation remains 0/30.
