# Real PD full decode-context coverage

Independent synchronized GPU profiler, not official E2E. vLLM 0.8.5 eager FP16 TP1, two H800 PCIe, requested 1P1D concurrency 1/2/4, input 1024/2048 and 128 output, 10 warmup and 30 measured waves each. All 560 requests returned expected input/output counts and backend IDs, and all consumer IDs had 127 decode steps. Each selected GPU forward event is joined to the actual client wave and batch. The audit groups only uniform-context steps and takes a median within each distinct wave; it does not count multiple requests in one batch as independent samples. Startup, heterogeneous-context batches and cross-wave batches are not used as uniform-shape points.

The strict audit found 255/1016 expected input/batch/context points passed >=10 warmup and >=30 measured waves: all 127 offsets for actual batch 1 at each input, plus one point at input 2048 batch 3. The remaining 761 fail or have no sample; 14,992 heterogeneous-context steps were excluded. Context offsets are sequence length minus input length (1–127). In particular, requested concurrent waves do not guarantee uniform actual batches. The pass count does not establish profile coverage for heterogeneous batches or complete non-overlapping CPU, sampler, KV or router costs. GPU events can include queuing gaps; detailed hooks and synchronization perturb execution. Do not use these rows as frozen costs before resolving missing shapes, context interpolation and service/simulator execution semantics.

Formal validation remains 0/30; no fee was fitted to validation data. Raw logs, ID map and failed/incomplete coverage are retained. Both GPUs released after collection.

## Heterogeneous-context characterization

A separate audit of all mapped decode steps found that, in the 30 measured requested-concurrency-4 waves, actual batch 4 consistently mixed contexts separated by one token: 3780 steps for each input length across 30 waves. For 2048 input at requested concurrency 2, actual batch 2 had a one-token context span in 3654 steps across 29 waves. All measured mixed steps in these categories had max span one. The simulator uses average KV context as a prediction feature, but these observations do not establish that equal average implies equal attention time. This property is specific to this diagnostic and is not guaranteed for validation or other scheduling. Distinct steps within a wave are correlated. Audit code, detailed summary, and raw samples are retained.
