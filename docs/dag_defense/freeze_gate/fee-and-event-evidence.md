## Decisions needed to close the remaining fee gate

1. Enumerate actual candidate matrix replay lookup keys with input hashes and identify which of the 53 strict missing cells are reachable, preserving failures. The existing strict-forward-adapter-20261126 already rejects a 1024-token batch-4 context-bin-1040 lookup; its concurrent-only zero first-token charge is a diagnostic omission, not an acceptable fee.
2. For each reachable missing key, collect an independent matching measurement or define a justified, explicitly versioned interpolation with range and uncertainty; do not fit to validation completion times. If no defensible coverage is possible, narrow the supported matrix with explicit approval or report the limitation and keep the full-matrix gate open.
3. Implement one common cost assignment for the adapted comparison, prove matching batch fee parity and check overlap exclusions on 1/2/4. Keep pristine original results separately labelled; a predictor-adapted baseline cannot be called pristine.

Event timestamps and costs are different kinds of evidence. The documented tail can be disclosed as a limitation, but the incomplete KV/readiness and fee mappings cannot be silently relabelled as exact.
