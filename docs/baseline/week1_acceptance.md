## 6. 审核规则

- 没有原始命令和日志的结果标记为“证据不足”。
- SHA 或输入哈希不一致的结果不进入横向比较。
- Windows 预检不能代替 Linux 正式验收。
- DeepSeek trace 只做事件结构与重叠行为校准，不作为请求级真值。
- 失败不等于未交付；若错误、复现步骤和边界记录完整，可作为有效失败记录进入周总结。
- 任何核心逻辑修改必须另建 Issue/PR，并从第一周固定基线结果中隔离。
