# E：故障、重复事件与截断

已实现协调层abort，并接入Simulator运行异常处理。先中止执行器释放任务租约，再清理PD持有的源pin、源/目标reservation及对应块表，取消容量等待登记。清理错误保留在cleanup_errors；未确认释放的句柄继续保留，不伪造已释放状态。源端清理失败时仍尝试清理独立的目标端资源。

协调层abort重复调用不再次释放。失败后的PD宿主事件无效；正常路径的重复接收commit明确报错。接收事件先检查所有Stage传输图已完成，不能凭借已计划的完成时间发布KVReady。

时间截断保留活跃传输、源pin和两端存储，状态为in_progress；Simulator仍保留超限事件。该快照不作为成功完成或资源泄漏结论。真正的全局失败清空宿主队列并清理资源。

测试覆盖双请求提前调度、传输未完成即commit、目标容量等待时中止、传输中止、commit故障、重复commit、重复abort，以及真实Simulator.run下的截断与宿主异常。正常图terminal与StageEnd各一次仍由原回归检查。
