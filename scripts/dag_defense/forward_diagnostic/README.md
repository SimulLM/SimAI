# Strict measured-forward diagnostic adapter

Opt-in runtime adapter for the predictor-adapted diagnostic baseline and DAG. It is not pristine SimAI, a production fee mapping, or formal validation. It looks up real measured producer full-forward and 16-token context-binned consumer full-forward costs, replacing layer compute exactly once. CPU, sampler, first-token, transfer and frontend costs are not solved by this adapter. The synchronized GPU events may include gaps, so numerical scope and additivity remain open. Input requests must have the same input length, no chunking or mixed phase; Decode requests must advance one token, have context offset 1–127 and context spread <=1. Unknown/unqualified shapes raise `CoverageError`, without extrapolation. TP1/PP1 only. Trace records request IDs, contexts, lookup keys, costs and SHA-256 of both cost sources.

`FORWARD_PREFILL_CSV` and `FORWARD_DECODE_CSV` select the candidate tables; `FORWARD_DIAG_MODE=baseline|dag` and `FORWARD_DIAG_TRACE` select behavior and trace. Invoke `bootstrap.py` instead of `python -m vidur.main` with the same simulator CLI and the appropriate separate checkout on PYTHONPATH. Baseline results are explicitly adapted, never labelled pristine; retain an untouched-original replay as a separate comparator. A runnable diagnostic example and its four raw runs are in `docs/dag_defense/environment/diagnostics/strict-forward-adapter-20261126`. Its concurrent config intentionally sets first-token fee to zero to exercise shape coverage; it cannot be used for formal predictions.
